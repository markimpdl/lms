# E26 — Reports PDF (Actvet+LO only)

> **Breakdown gerado em 2026-04-26.** Spec consolidada em `doc/15-roadmap-pos-mvp.md` (F17, linhas 1021–1105).

## Contexto

Após o professor dar feedback completo (5 LOs com nota), gerar PDF formal com layout institucional Skills Hub. **Apenas pro professor** (aluno não vê em nenhum lugar). Re-submit do aluno + nova rodada de feedback regenera o PDF.

**Disponibilidade restrita**: tenants Actvet (`is_actvet=1`) com curso em `grading_mode='learning_outcomes'` E `report_mode='skill_hub'`. Casos fora: `report_mode` forçado `'disabled'` server-side.

**Pré-requisitos:** E24 (`is_actvet`) e E25 (LO mode + 5 LOs + grades por LO) — ambos fechados.

## Story E26-02: ReportService::generate(submissionId)

**Como** sistema, **quero** um service que gera o PDF de uma submissão **para que** a story de trigger possa chamar uma API limpa sem se preocupar com formatação/render.

**Complexidade:** M
**Depende de:** #E26-01 (schema + dompdf + template)
**Persona:** infra/service

### Critérios de Aceite
- [ ] Service novo `src/services/ReportService.php` com:
  - `generate(int $submissionId): array{status:string, path?:string, error_key?:string}` — gera PDF e retorna path relativo gravado
  - Validações internas: submissão existe, curso é Actvet+LO, `report_mode='skill_hub'`, todos os 5 LOs têm grade (caso contrário `status='not_ready'`)
  - Lê dados via queries enxutas: course/UC/student via JOIN; LOs via `LearningOutcome::findByCu`; grades via `LearningOutcome::findGradesBySubmission`
- [ ] Variáveis substituídas via `str_replace` antes do dompdf (catálogo no doc):
  - `{{NAME_COURSE}}` `{{NAME_STUDENT}}` `{{NAME_UC}}` `{{WORKLOAD_UC}}` (formato `30h`)
  - `{{AVG_LEARN}}` — média dos 5 LO scores × 10 (inteiro quando exato; 1 decimal se necessário, ex.: `85` ou `85,2`)
  - `{{LEARN_1_NAME}}` … `{{LEARN_5_NAME}}` — descrição de cada LO
  - `{{LEARN_1_SCORE}}` … `{{LEARN_5_SCORE}}` — grade × 10 (inteiro sempre)
- [ ] Variáveis fora do catálogo: ficam literais no PDF (debug-friendly, decisão consolidada na spec)
- [ ] dompdf renderiza o HTML com `setBasePath` apontando pra `public/assets/report-templates/skill_hub/` pra `<img>` relativos funcionarem
- [ ] Output salvo em `storage/reports/eval_{evalId}_student_{studentId}_attempt_{N}.pdf`
- [ ] Path retornado é **relativo a LMS_ROOT** (ex.: `storage/reports/eval_42_student_7_attempt_1.pdf`) — gravado em `evaluation_submissions.report_pdf_path` pelo caller (E26-04)
- [ ] Re-geração: sobrescreve arquivo existente sem mexer no path

### Tarefas técnicas
- [ ] Criar `src/services/ReportService.php`
- [ ] Implementar `generate()` com queries + validações + render
- [ ] Helper privado `formatGrade(float $grade): string` (×10, inteiro vs decimal)
- [ ] Helper privado `formatWorkload(int $hours): string` (`30h`)
- [ ] Loader do template via `file_get_contents` + `str_replace`
- [ ] Instanciar dompdf com `enable_remote=false` + `enable_html5_parser=true` + `setBasePath`
- [ ] `php -l` antes do commit

## Story E26-04: Trigger pós-último-LO + endpoint pro professor

**Como** professor, **quero** que o report seja gerado automaticamente quando termino o feedback E ter um link pra baixar o PDF **para que** eu não precise apertar nenhum botão extra.

**Complexidade:** M
**Depende de:** #E26-02 (ReportService) + #E26-03 (config no curso)
**Persona:** professor (Actvet)

### Critérios de Aceite
- [ ] `EvaluationSubmissionService::gradeByLo` (de E25-03) ao terminar com sucesso: detecta se curso é `report_mode='skill_hub'` E todos os 5 LOs têm grade → chama `ReportService::generate($submissionId)`; persiste `report_pdf_path` na `evaluation_submissions`
- [ ] **Não dispara** quando `report_mode='disabled'` ou quando UC não tem 5 LOs (defesa redundante; service também valida)
- [ ] Re-correção (segunda rodada de feedback): regenera PDF, sobrescreve arquivo, atualiza `report_pdf_path` (mesmo se path não mudou)
- [ ] Trigger é **best-effort**: falha do dompdf não rola back o feedback (log + segue); flash warning opcional
- [ ] Rota nova `/teacher/evaluation/{id}/submission/{sid}/report.pdf`:
  - Valida ownership: tenant do prof + submission pertence
  - Lê `report_pdf_path`; se NULL → 404
  - Lê arquivo de `storage/reports/...`; se inexistente → 404 (path órfão)
  - Serve com headers `Content-Type: application/pdf`, `Content-Disposition: inline; filename="report-NNN.pdf"`
- [ ] Link "Baixar Report" na tela `/teacher/evaluation/{id}/submission/{sid}` — visível apenas quando `report_pdf_path` não-NULL (sempre que houver feedback completo)
- [ ] Aluno não vê o link em nenhum lugar (no envio, no histórico, no card de feedback)
- [ ] CSRF no link? Não — é GET de download, não POST destrutivo

### Tarefas técnicas
- [ ] Hook em `EvaluationSubmissionService::gradeByLo` chamando `ReportService::generate` no fim da transação (ou pós-tx — best-effort)
- [ ] UPDATE `evaluation_submissions.report_pdf_path` com retorno do service
- [ ] Nova rota `/teacher/evaluation/(\d+)/submission/(\d+)/report.pdf` em `src/routes.php`
- [ ] Nova page `src/pages/teacher/evaluation/report-pdf.php` (handler de download)
- [ ] Atualizar `submission.php` com link condicional
- [ ] `lang/pt.php` + `lang/en.php`: chaves `evaluations.grade.report_download` + `evaluations.grade.report_unavailable`
- [ ] `php -l`

3. **E26-03** — config `report_mode` no curso (paralelo a #E26-02 se quiser)

Cada story = 1 PR pra `develop`. Release MINOR (`v0.23.0`) ao fim do épico.

## Pendências esperadas

- **Composer dep nova (`dompdf`)**: a primeira que tem peso de runtime (PHPMailer já entrou em E10-03). Validar que `composer install` em prod (Hostinger) não dá fricção.
- **Path do template + base href**: dompdf precisa de `setBasePath` correto pra `<img src="images/...">` resolver. Testar localmente antes de prod.
- **Storage de PDFs em `storage/reports/`**: criar diretório com permissões corretas (PHP escreve, web nega leitura direta). `.htaccess` deny + endpoint serve.
- **Re-cadastro de LOs (E25 pendência)**: se o professor edita os 5 LOs após gerar reports, o template fica desalinhado (descrições novas, notas antigas/inexistentes). Anotar em `doc/99` se virar problema.
